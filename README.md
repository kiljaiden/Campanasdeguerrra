# Campanasdeguerrra
Campañas de Guerra (WoW 3.3.5a) une temporizadores de BGs (Capping) y un sistema JcJ en mundo abierto (estilo Overlord) sincronizado entre jugadores sin servidor. Conquista 58 frentes y fortalezas, gestiona minas y madera, sube 15 rangos, caza némesis y domina el mapa con su interfaz dorada y carmesí (/campanas)
